Project Title: Talentiaa - AI-Powered Applicant Tracking System (ATS)

Project Features:
By the end of this course, implemented features: 
1. Role-based Authentication (Admin, Recruiter, Candidate)
2. AI-Powered Resume Scoring & Matching (using Groq AI / Llama 3.3)
3. Automated Job Description Generation using AI
4. Kanban Board Pipeline with Drag & Drop functionality
5. Real-time Application Trend & Stage Analytics (using Recharts)
6. Automated Email Notifications on Application Stage Change (EmailJS)
7. "Hidden Pool" logic to auto-filter candidates below a threshold AI score
8. Public Job Board with real-time experience level filtering
9. Admin Dashboard with one-click CSV Data Export capabilities
